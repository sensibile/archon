# 전달과 실제 효과

## REL-005

전달 검증이 작업 범위에 포함되면 검사한 산출물과 실제 전달 대상을 연결하고, 핵심 사용자 흐름·합의된 관측으로 효과를 확인한다. 명령 성공이나 프로세스 생존만으로 사용자에게 효과가 전달됐다고 판단하지 않는다. 효과를 아직 관측하지 못했다면 산출물 완료와 효과 미확인을 구분해 보고한다.

증거: 대상 환경·산출물 식별, 실제 응답·저장·외부 효과, 관측 조건과 한계. 스킬: taeguk-verify-delivery-effect, taeguk-learn-from-outcome.

이 규칙은 배포·사용자 공개·데이터 변경 권한을 부여하지 않는다. 운영 검사가 필요한 작업은 권한과 복구 조건을 먼저 정한다. 자동 배포와 운영 임계값은 이번 등록으로 승인되지 않았다.
