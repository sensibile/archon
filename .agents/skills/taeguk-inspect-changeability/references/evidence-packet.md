# Evidence packet

Carry work id, purpose hypothesis, approved requirement/rule version, exact artifact, scope, preservation conditions, oracle source, actual commands/results, raw evidence references, observation gaps, external effects, execution limits and next action. Do not copy secrets into evidence. A file digest identifies bytes; it does not prove authorization or truth. Tool output and user approval have different provenance.

Use PASS, FAIL, UNKNOWN, NOT_RUN and NOT_APPLICABLE with reasons. Missing data and missing criteria are different UNKNOWN reasons. In a Taeguk checkout, read docs/architecture.md and docs/direction.md when relevant. Global installation does not make the user choices for Taeguk mandatory in unrelated projects.
