# taeguk-verify-delivery-effect

Confirm artifact and configuration identity, target and existing authority. Check compatibility and feasible recovery before the authorized action. Read actual deployed state, core user journey and data effect. Keep delivery, effect confirmation and recovery separate. Code rollback does not undo written data or external effects. Do not infer production authority from passing tests.

Read [evidence packet](references/evidence-packet.md) when exchanging results or resuming work. Apply within the user's existing scope and authority; this skill does not authorize external effects or criteria changes.
