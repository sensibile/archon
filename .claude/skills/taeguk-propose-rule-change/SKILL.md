# taeguk-propose-rule-change

Record current rule version and problem case. Compare old and proposed criteria on identical positive and negative cases. Explain newly permitted or rejected behavior, cost, rollout and reversal conditions. Present to BOSS for confirmation. Keep existing approved criteria until confirmed; never change a threshold to pass the current implementation.

Read [evidence packet](references/evidence-packet.md) when exchanging results or resuming work. Apply within the user's existing scope and authority; this skill does not authorize external effects or criteria changes.
