# taeguk-learn-from-outcome

Separate output, user behavior/outcome and Mission hypothesis. Record observation period, exposure and attribution limits. Compare expected effect with actual user burden, failures and manual intervention. Distinguish product hypothesis, implementation and workflow problems. Propose the next bounded experiment or no change; a metric gain alone is not value evidence.

Read [evidence packet](references/evidence-packet.md) when exchanging results or resuming work. Apply within the user's existing scope and authority; this skill does not authorize external effects or criteria changes.

목적에 대한 완료 검토는 /taeguk-work-contract의 참고를 사용한다. 미확인을 나열하는 대신 수행한 조사·결론에 미치는 영향·남은 다음 행동을 연결한다. 이번 과제의 누락과 후속 실험을 구분하고, 해결 가능한 기존 과제를 임의로 다음 과제로 돌리지 않는다.

When the user authorizes repairing Taeguk itself, continue with /taeguk-self-improve rather than ending at a follow-up proposal. Carry the raw retrospective evidence and distinguish observed defects from hypotheses.
