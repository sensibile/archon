# taeguk-investigate-and-reproduce

Separate facts from hypotheses. Inspect the actual path and affected version. Compare competing causes and choose a minimal experiment. Record initial state, inputs, observed effects and failure. For lost responses, query actual effect before retry. Keep weak signals as investigation candidates; no change is a valid result.

Read [evidence packet](references/evidence-packet.md) when exchanging results or resuming work. Apply within the user's existing scope and authority; this skill does not authorize external effects or criteria changes.
