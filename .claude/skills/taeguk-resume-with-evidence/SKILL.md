# taeguk-resume-with-evidence

Read the prior decision and evidence packet, then query actual state, artifact and current authorization. Classify pending, confirmed success, confirmed failure and unknown effect. Do not rerun effectful operations just because a response was lost. Continue independent authorized work when one branch is blocked. Record next action and unresolved condition.

Read [evidence packet](references/evidence-packet.md) when exchanging results or resuming work. Apply within the user's existing scope and authority; this skill does not authorize external effects or criteria changes.
